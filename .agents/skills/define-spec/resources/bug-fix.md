# Specify a bug fix

- In **Problem**, give the steps to reproduce the bug. State the observed and expected results. Link to the evidence and the rule, if available. Mark the report as unconfirmed if you cannot reproduce it.
- In a prescriptive **Solution**, specify a regression test in the relevant part. The test must fail before the fix and pass after it.
- In prescriptive **Verification**, cover the expected result for the reported case.
