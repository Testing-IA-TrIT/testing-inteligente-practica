# Specify a refactor

- In **Problem**, state the technical objective and the observable behavior to preserve. Link to its existing criteria or tests, if available.
- In **User stories**, use the user goals that the change must preserve.
- In a prescriptive **Solution**, specify which tests to run before and after the change. Reuse existing tests. If coverage is missing, specify a test that captures the current result before the refactor.
- In prescriptive **Verification**, cover the observable results to preserve.
